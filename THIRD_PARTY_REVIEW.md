# Third-party provenance review

This file is an inventory aid, not a replacement for license texts or a conclusion
that every item can be offered under one root license.

- Python and JavaScript dependency manifests retain their original package versions
  and lockfile license/integrity data. Resolve the actual distributable dependency
  inventory and notices for the release artifacts.
- Backend Flux integration references upstream implementations, including Prosopo.
  Optional translated CLI source and imported provider API documentation are omitted
  from this snapshot; their exclusion does not establish independence of all backend
  expression. Compare upstream revisions and retain required notices.
- Dashboard UI primitives reference shadcn/Radix/Lucide ecosystems. Copied/generated
  source attribution requires verification beyond package manifests.
- Protocol images download Xray and inherit system packages/Squid/OpenSSH and other
  software with separate obligations. Image digests, notices and source availability
  must be reviewed before image redistribution.
- An unverified binary favicon and the optional landing page are omitted.

Existing license/notice and copyright text must be preserved. Do not claim this
review or a clean secret scan grants rights that are still unresolved.
